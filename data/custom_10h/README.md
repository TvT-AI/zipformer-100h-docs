# Custom 10h Meeting Dataset

This directory is intended for the Custom 10h Meeting dataset.
Due to privacy and confidentiality agreements, the audio and transcripts for this dataset are strictly internal and cannot be distributed publicly.

If you are an internal team member, please request access to the dataset archive and extract it here to run the benchmarks.

Expected format:
- `recordings.jsonl`
- `supervisions.jsonl`
- `wavs/` (Directory containing 16kHz audio segments)
