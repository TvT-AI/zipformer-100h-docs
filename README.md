# Zipformer ASR Benchmark Toolkit

This repository contains the benchmark results and deployment configuration for Zipformer ASR models on Vietnamese datasets. It utilizes HuBERT self-supervised learning (SSL) and pseudo-labeling on internal meeting datasets.

Note: This repository is intended solely for evaluation and inference. Training code and recipes are maintained in a separate internal repository.

## 2. Evaluation Datasets

All empirical evaluations were performed using 16kHz WAV PCM 16-bit mono audio.

| Dataset | Purpose | Duration | Samples | Format | Local Availability | Annotation Source |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| Custom 10h Meeting | Internal Test | 10.0 h | 10,616 | 16kHz WAV | Private | Whisper ensemble pseudo-labels, human-verified |
| VIVOS Test Set | Standard benchmark | 1.5 h | 760 | 16kHz WAV | Public (`data/vivos/test`) | AILab HCMUS |
| VLSP 2020 Test Set | Noisy benchmark | 2.1 h | 1,613 | 16kHz WAV | Public (`data/vlsp_2020`) | VLSP 2020 |
| FLEURS Vietnamese | Multilingual | 2.4 h | 857 | 16kHz WAV | Public (`data/fleurs`) | Google FLEURS |
| GigaSpeech 2 (VN) | Paper reference | 50 h | ~35,000 | N/A | Not available | SpeechColab |
| Common Voice 17.0 (VN)| Paper reference | 30 h | ~22,000 | N/A | Not available | Mozilla |

**Note regarding Custom 10h dataset:** 
This evaluation dataset was derived from a larger internal corpus of YouTube meeting videos. The dataset creation pipeline is as follows:
1. **Segmentation**: Raw audio was segmented using FunASR VAD.
2. **Pseudo-labeling**: Segments were transcribed using an ensemble of Whisper Large and Whisper Medium.
3. **Filtering**: Segments with a Word Error Rate (WER) difference > 5% between the two Whisper models were discarded.
4. **Human Verification**: A random 10-hour subset of the high-quality segments was extracted and manually relabeled by human annotators to establish a gold-standard test set.
5. **Training & Evaluation**: The `Zipformer SSL 100h` model was trained on the remaining 100 hours from this corpus. All models in this benchmark are evaluated against the 10-hour human-annotated test set to assess domain-specific performance.

*Due to privacy constraints, the audio and transcripts for this internal dataset are not provided in this repository.*

## 3. Zipformer SSL 100h Deployment

The `Zipformer SSL 100h` model was fine-tuned from a HuBERT pre-trained checkpoint using 100 hours of Vietnamese data over 9 epochs. The final inference model was produced by averaging the checkpoints from epochs 5 through 9 to improve generalization and stability. The averaged model and our custom `bpe.model` were then exported to ONNX format for deployment via `sherpa-onnx`.

```text
models/zipformer_ssl_100h/
├── encoder-epoch-9-avg-5.onnx   # Averaged encoder from epoch 5 to 9
├── decoder-epoch-9-avg-5.onnx   # Stateless decoder
├── joiner-epoch-9-avg-5.onnx    # Joiner for Pruned Transducer loss
├── bpe.model                    # SentencePiece BPE tokenizer
└── tokens.txt                   # Token-to-ID mapping
```

Inference uses `sherpa_onnx.OfflineRecognizer.from_transducer(...)` with `greedy_search` decoding.

## 6. Training Loss Trajectories

![Validation Loss Trajectories](docs/loss_plot.png)

Analysis of Loss Convergence:
1. Self-Supervised Pre-training (Figure 1a): Iterative pre-training utilizing optimized pseudo-labels resulted in a sharp decrease in Cross-Entropy loss:
   - Iteration 1 (9 epochs): Validation Loss reached 1.753.
   - Iteration 2 (18 epochs): Validation Loss decreased to 1.085.
   - Iteration 3 (18 epochs): Validation Loss converged to 0.302.

2. Downstream Fine-tuning Zipformer (Figure 1b): Models initialized from higher pre-train iterations demonstrated superior convergence rates and achieved noticeably higher accuracy:
   - Pruned Transducer Validation Loss dropped from 1.322 (Iteration 1) to 1.227 (Iteration 3).
